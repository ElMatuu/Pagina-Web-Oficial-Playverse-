02 · Streaming

Compartí el momento.

La aplicación contiene integración técnica de LiveKit y flujos de emisión y reproducción. No se anuncia como servicio disponible: faltan credenciales operativas y pruebas reales de extremo a extremo.

  • Área de transmisiones y salas.
  • Experiencia de visualización social.
  • Creación autenticada de sesiones y tokens de corta duración.
  • La emisión y reproducción requieren configurar LiveKit y validar cámara, micrófono, pantalla y dispositivos.
No se muestra una transmisión falsa: la disponibilidad en vivo depende de que el servicio de streaming esté configurado y operativo.

08 · Guías de instalación

Instalación simple, paso a paso.

Mientras se preparan los instaladores nativos, podés acceder como aplicación web desde tu dispositivo.

▣

Android y tablets

  1. Abrí Chrome y visitá esta página o la aplicación PlayVerse.
  2. Entrá a la aplicación desde el botón de acceso.
  3. Abrí el menú del navegador.
  4. Elegí “Instalar aplicación” o “Agregar a pantalla principal”, si aparece.
  5. Confirmá para crear el acceso directo.
El APK nativo todavía no está publicado. Descargalo únicamente desde esta página cuando aparezca el enlace oficial.
▤

Windows 10 y 11

  1. Abrí Edge o Chrome.
  2. Visitá la aplicación PlayVerse.
  3. En Edge, abrí Aplicaciones; en Chrome, buscá “Instalar página como aplicación”.
  4. Confirmá y abrí PlayVerse desde el menú Inicio.
  5. Usá siempre la versión actualizada del navegador.
El instalador .exe se publicará cuando el paquete de escritorio esté generado y probado.
09 · Centro de ayuda

Preguntas frecuentes.

Información clara sobre la plataforma, sus descargas y su disponibilidad.

¿PlayVerse es Omlet Arcade?

No. PlayVerse es un proyecto independiente con identidad propia. Toma inspiración de la experiencia social gamer, pero no se presenta como el producto oficial de Omlet Arcade ni utiliza su marca.

¿Dónde descargo el APK?

El enlace aparecerá en la sección Descargas cuando exista un APK oficial firmado y verificado. Hoy no hay un APK publicado desde esta web.

¿Dónde descargo el instalador de Windows?

El instalador EXE aparecerá cuando el build de Windows esté terminado, probado y publicado como release.

¿Puedo usar PlayVerse ahora?

La aplicación web tiene una base de autenticación y servicios sociales en desarrollo. La integración de todas las pantallas y la validación completa en producción todavía están pendientes; algunas funciones requieren servicios externos configurados.

¿La web se actualizará automáticamente?

El sitio está separado en su propio repositorio y se publicará desde ahí. Con el despliegue automático habilitado, cada actualización aprobada de la rama principal podrá reflejarse en la web.

¿Dónde puedo ver capturas reales?

La galería de capturas reales se publicará cuando las pantallas se hayan obtenido de una versión de PlayVerse en ejecución y se hayan validado. No usamos imágenes ilustrativas para hacerlas pasar por la aplicación.
